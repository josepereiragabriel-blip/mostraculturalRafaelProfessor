# Projeto: Filtragem de Notas de Alunos com Python

Este repositório contém um script desenvolvido para a disciplina de [analise e método para sistemas]. O objetivo do código é demonstrar a manipulação de dados utilizando estruturas nativas do Python para filtrar alunos aprovados com base em suas notas.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Conceitos Praticados:** Estruturas de dados (Dicionários e Listas), laços de repetição (`for`) e estruturas condicionais (`if`).

## 💻 Como Executar o Script
1. Certifique-se de ter o Python instalado em seu computador.
2. Baixe ou clone este repositório.
3. No terminal ou prompt de comando, navegue até a pasta do projeto e execute o arquivo:
```bash
python script.py
```
